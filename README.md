**Banking Data Analytics Dashboard – Power BI Project**

This project is an End-to-End Data Analytics Dashboard built using Power BI to analyze banking data and generate meaningful business insights.
The dashboard focuses on customer data, transactions, and financial performance using interactive visualizations and KPIs.

The project includes data cleaning, transformation, data modeling, DAX calculations, and dashboard creation to convert raw data into useful insights.

**Features**

1) KPI Cards (Total Customers, Balance, Transactions, Loans)

2) Customer Segmentation Analysis

3) Region / Branch wise performance

4) Account type distribution

5) Monthly / yearly trend analysis

6) Interactive filters & slicers

**Tools & Technologies**

1) Power BI Desktop

2) Power Query

3) DAX (Data Analysis Expressions)

4) Excel / CSV Dataset

5) Data Modeling

**Key Insights from Dashboard**

Identified high balance customers and active accounts

Found which branch has maximum transactions

Analyzed customer distribution by account type

Observed monthly trends in deposits and withdrawals

Compared loan amount vs customer count

Detected top performing regions
